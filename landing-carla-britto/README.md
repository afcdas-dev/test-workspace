# Landing Page — Dra. Carla Britto (Biomédica Tricologista)

Landing page estática de alta conversão para o perfil
[@carlabritto.biomed](https://www.instagram.com/carlabritto.biomed/),
focada em agendamento de avaliações capilares via WhatsApp.

Arquivo único (`index.html`), sem dependências nem build — basta hospedar em
qualquer serviço de páginas estáticas (Netlify, Vercel, GitHub Pages, Hostinger etc.).

## Estrutura de conversão

1. **Hero** — headline de dor + CTA WhatsApp + prova de confiança;
2. **Faixa de números** — prova social imediata;
3. **Dores** — identificação do visitante com os sintomas;
4. **Método em 3 passos** — reduz incerteza sobre o processo;
5. **Tratamentos** — o que é oferecido;
6. **Sobre** — autoridade da profissional;
7. **Depoimentos** — prova social;
8. **FAQ** — quebra de objeções (preço, online, tempo de resultado);
9. **CTA final com urgência** + botão flutuante de WhatsApp + barra fixa no mobile.

## Antes de publicar (obrigatório)

- **WhatsApp**: substitua `5511999999999` pelo número real (formato `55` + DDD + número)
  em todos os links `wa.me` — busque por `5511999999999` no `index.html`.
- **Foto**: os círculos com as iniciais "CB" (classe `.hero-photo`) são placeholders;
  troque por uma foto real da Dra. Carla para aumentar a conversão.
- **Números da faixa de prova social** (ex.: "+500 avaliações"): ajuste para números reais.
- **Depoimentos**: substitua os textos ilustrativos por depoimentos reais autorizados
  (e remova a nota de rodapé da seção quando fizer isso).
- **Endereço**: confirme o endereço do consultório exibido no rodapé e no FAQ.
- **Pixel/Analytics**: se for rodar tráfego pago, adicione o Meta Pixel / GA4 no `<head>`.
